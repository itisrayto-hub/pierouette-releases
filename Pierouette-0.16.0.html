What's new in 0.16.0

  • **The app is Rayto** — new name, new icon (a silver ribbon: an 8 on its way to ∞), a new intro. Your menus, shortcuts and settings carry over unchanged
  • **Opens like any Mac app** — Rayto is now signed and notarized by Apple: no "damaged" warning, no right-click → Open, no trip to Privacy & Security to get it running
  • **Layers** — every menu can hold several layers of pills, one showing at a time. On an open menu press a layer's key (1, 2, 3…) to switch — deeper layers come up from far away, going back is the same film in reverse. Make layers in Arrange: the row above the bar ("1 2 3 +") — right-click a number to name it, pick its key, make it the layer the menu opens on, or delete it
  • **Setup, rebuilt** — one permission, then two short lessons (tap the key · hold it and swipe) on a practice menu that fires nothing real; trying a different key on the setup page is undone unless you press Continue
  • **File pills** — drop a file anywhere on the editor's right side to use it; Change… opens in the folder the current file lives in
  • **The pill editor never grows** — the form scrolls, Add and Cancel stay where they are; the Add Pill search takes the arrow keys
  • **Corner dial** — the app under the dial no longer reacts to your pointer while you turn it
  • **Keyboard locked?** — when a password prompt has locked the keyboard (macOS Secure Input), the menu's caption says so instead of ignoring your keys
  • **No Screen Recording request** — the app never asks for Screen Recording unless you turn on the iPhone display
  • **Sounds** — the default hover and navigation clicks now ship with the app (free, CC0 sounds)
  • **Feedback goes to hello@rayto.app** — the crash report and the feedback window write there; a false "quit unexpectedly" on a fresh install is fixed
