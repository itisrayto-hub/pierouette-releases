What's new in 0.8.7

  • Arrange mode now edits deliberately: clicking a pill no longer opens its editor — right-click it, then click the pencil badge
  • Entering edit mode plays the menu-open sound
  • Pills look identical everywhere: the outer (⌥) ring in Arrange renders each pill exactly as the live menu does, labels included
  • Edit mode no longer prints keyboard shortcuts on pills — that information lives in the tooltip only
  • Arrange rearrangement got the list treatment: empty slots trade places live in both directions, and every drop settles from under your cursor with no flicker
