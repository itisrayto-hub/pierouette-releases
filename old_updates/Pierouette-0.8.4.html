What's new in 0.8.4

  • Faster everywhere: eliminated multi-frame freezes when hovering a disk-image file pill, snapping windows, and on the App Launcher's first swap
  • The menu now opens fully on screen when triggered near edges and corners
  • The Window menu now works on small windows in screen corners
  • One action, one sound: doubled-up sound effects removed; opening and closing a folder now share the hover sound
  • Alternative (⌥) pills: the confirmation and toast now always show the face you actually fired
  • Bigger pill previews in Settings lists
  • ⌘, opens Pierouette's settings while a menu is open
  • Fix: changing a shortcut's action type clears the old hotkey so both can't fire
