What's new in 0.8.8

  • Keyboard navigation matches the ring: arrow keys walk the pills in true clockwise order (they used to follow the original layout after rearranging)
  • Arrow keys now work in menus reached through the Compass (they went silent after a Compass switch)
  • Compass: pressing an arrow key instantly opens the menu in that direction — the Compass is the four arrows
  • Mode flip works both ways: an empty mode no longer traps the keyboard (down-arrow appeared dead)
  • Closing a menu without firing sounds the same everywhere — one soft close sound in every menu
  • The auto-recenter sound now follows the movement: longer flights sound longer and louder, it starts when the cursor visibly moves, tiny corrections stay silent — and long Compass glides got their full length back (they ran fast and quiet on a mis-measured distance)
