What's new in 0.10.0

  • The menu and its folders now behave identically everywhere. Every gesture — hovering, flicking, arranging, the pill that stays lit after a slow swipe — runs on one shared rulebook for both rings, so a folder can never react differently than the main menu again
  • The first interaction after opening is instant: the graphics warm up in the background at launch, removing the slow first hover
  • Arrange mode feels tighter: all wiggling pills rock in sync, the pill you grab always rides above everything else, and a linked pair's grey link mark stays glued to its pair through every drag and swap
  • Moving a lit pill's selection to another pill now needs actual contact with the new pill — fast sweeps past other pills no longer steal the selection
  • The arrows inside folders now give the same hover sound as everything else
